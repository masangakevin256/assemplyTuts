Assembly Language Tutorial

Learn the fundamentals of assembly programming

Data Types & Fundamentals

Integer Constants

Syntax:

+ - , h, d , b

Examples:

30d, 30, 6Ah, 100101b
Integer Expressions

Operator Precedence:

  • 1. () - parentheses
  • 2. +, - - Unary Plus, Minus
  • 3. *, /, MOD - Multiplication, Division, modulus
  • 4. +, - - add, subtract
Character Constants

Enclosed in Single or double quotation marks

Examples:

'A', "B", "C", "D", "E", "F", "G", "H"
String Constants

Enclosed in double quotation marks

ASCII character = 1 byte

Example:

"Hello World"
Reserved Words

Keywords that have special meaning to the compiler. They can't be used as identifiers.

Examples:

mov, dec, add, + etc
Identifiers

Names given to variables, constants, labels, etc.

Examples:

Var21, $var21, _var21
  • They are not case sensitive
  • They can't start with a number
  • They can't be reserved words
Directives

Instructions that tell the assembler what to do

Examples:

.data, .code, comments
  • .data - identifies the area that contains variables and constants
  • .code - identifies the area that contains the program
  • comments - identifies the area that contains comments
Registers

Used to store data

Examples:

EAX, EBX, ECX, EDX

Example usage:

MOV eax, 100
  • EAX - Extended Accumulator - 4 bytes
  • EBX - Extended Base - 4 bytes
  • ECX - Extended Counter - 4 bytes
  • EDX - Extended Data - 4 bytes
Labels

Used to mark a location in the program

Examples:

Label1, Label2, Label3

Example usage:

Subscribe: DWORD 100
Instructions

The actual code that is executed by the computer

Examples:

mov, add, sub, mul, div, mod, inc, dec, push, pop, call, ret

Common instructions:

  • mov - move data from one location to another
  • add - add two numbers
  • sub - subtract two numbers
  • mul - multiply two numbers
  • div - divide two numbers
  • mod - modulus of two numbers
  • inc - increment a number
  • dec - decrement a number
  • push - push a value onto the stack
  • pop - pop a value from the stack
  • call - call a procedure
  • ret - return from a procedure
Flags

Used to store the result of an instruction

  • OF – Overflow Flag: Set when the signed result is too large or too small
  • CF – Carry Flag: Set when an arithmetic operation generates a carry
  • PF – Parity Flag: Set if the result has an even number of 1 bits
  • ZF – Zero Flag: Set if the result is zero
  • SF – Sign Flag: Set if the result is negative
Sizes

Used to specify data size

  • DWORD - Double Word - 4 bytes
  • WORD - Word - 2 bytes
  • BYTE - Byte - 1 byte

Common Instructions

MOV Instruction

Move data from one location to another

Example:

MOV eax, 100 ;move the value 100 into the register eax
ADD Instruction

Add two numbers

Example:

ADD eax, 100 ;add the value 100 to the register eax
SUB Instruction

Subtract two numbers

Example:

SUB eax, 100 ;subtract the value 100 from the register eax
MUL Instruction

Multiply two numbers

Example:

MUL eax, 100 ;multiply the value 100 with the register eax
DIV Instruction

Divide two numbers

Example:

DIV eax, 100 ;divide the value 100 with the register eax
INC Instruction

Increment a number

Example:

INC eax ;increment the value in the register eax
DEC Instruction

Decrement a number

Example:

DEC eax ;decrement the value in the register eax
PUSH Instruction

Push a value onto the stack

Example:

PUSH eax ;push the value in the register eax onto the stack
POP Instruction

Pop a value from the stack

Example:

POP eax ;pop the value from the stack into the register eax
CALL Instruction

Call a procedure

Example:

CALL procedure ;call the procedure
RET Instruction

Return from a procedure

Example:

RET ;return from the procedure
